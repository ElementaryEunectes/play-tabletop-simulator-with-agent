# HARNESS_HOME_AGENTS.template.md —— 放到 harness home 的"通用纪律"模板

> **这份不是给本仓库读的**（本仓库的项目纪律在 `AGENTS.md`）。它是**跨项目那份**的可版本化源。
>
> **放哪**：`$DSH_HOME\AGENTS.md`（DSH 的"用户全局"指令文件 —— **每次请求都注入**，所以只放放之四海皆准的条目）。
> **怎么装**：改本文件 `---` **以下的正文** → 整段覆盖到 `$DSH_HOME\AGENTS.md`（该路径在工作区之外 ⇒ 需要**一次提权**）。
> 本仓库的 `tts\tests\test_agents_hygiene.ps1` 会核对"全局那份与这里的正文逐字一致"（漂移检查）—— 装完跑一次它。
>
> ⛔ 模板正文里不许出现任何机器专属内容（用户名、绝对路径、本机端口）。那些属于**项目目录下的 `AGENTS.local.md`**（overlay，不进仓库）。

## 隔离机制（DSH 的实际规则，2026-10-08 读源码确认）—— **这段不进正文，别拷**

- **注入什么**：① `$DSH_HOME\AGENTS.md`（用户全局，**文件名是常量**，存在就第一个加，**与 cwd 无关**）
  ② **项目根 → cwd 的项目链**（项目根 = 从 cwd 向上第一个含 `.git` 的目录；**一个都没有时项目根 = cwd 自身**），
  每级找 `AGENTS.md` / `CLAUDE.md`，再找 `AGENTS.local.md` / `CLAUDE.local.md`。
- **去重只有两种**：**绝对路径**去重（同一份文件不会算两次）＋ **同目录内**去掉 trim 后内容相同的兄弟文件。
  源码原话：**跨目录即使内容完全相同也绝不合并**。最后按**字节预算**渲染（超了先丢"更宽泛的"，即离 cwd 更远的）。
  ⇒ "只有通用槽"的会话 = 从**仓库外、且该目录没有那四个候选文件**的地方起会话（或 cwd 设成 `$DSH_HOME` 本身：链扫到的是同一绝对路径，被去重）。
- ⛔ **没有"忽略用户全局那份"的开关**（`USER_GLOBAL_FILE` 是常量，`instructionFileCandidates` 只管项目链）
  ⇒ 想让全局那份不参与注入，只有两条：① `$DSH_HOME` 里没有它；② **把 `DSH_HOME` 钉到项目根**（两槽同一绝对路径 ⇒ 去重成一份）。
  ⚠️ ②的代价：`DSH_HOME` 同时是 harness 的家（sessions / 凭据 / profiles）⇒ 已有状态的机器要搬迁；**新机器从一开始这么配则没有代价**。
- 改文件会触发**再注入**（会话中途改它，harness 会推一条变更提醒把新内容补进来）⇒ 每次改都在为它付钱。

# AGENTS.md —— 平台宪章（**跨项目不变**）

> **每次请求都注入并计费** ⇒ 只放放之四海皆准的条目。
> ⛔ 不放任何单一项目的领域知识（某项目怎么干活、某局游戏的坐标/规则/状态）—— 那些放**该项目自己的文档**；**发现混进来就立刻搬走**。
> 可版本化源：仓库 `tts\docs\HARNESS_HOME_AGENTS.template.md`（改那份 → 取 `---` 以下的正文拷到这里）。

## 1. 文件与编码

- **含中文的 `.ps1` 必须 UTF-8 带 BOM**：PS 5.1 把无 BOM 当 ANSI 读 ⇒ 中文变乱码 ⇒ **语法报错、脚本"秒挂"**
  （编辑工具常**悄悄丢 BOM**；"读字符串再写回"还会每跑一次**多叠一个 BOM**）。⇒ **改完任何 `.ps1` 都用真解析器校验一次**，别只靠"能跑起来"。
- 一次性脚本**注释与输出尽量 ASCII**；改前先 read；**一次只动一处**，改完回读。

## 2. 执行

- `& xxx.ps1` 可能被策略挡下 ⇒ 一律 `powershell -NoProfile -ExecutionPolicy Bypass -File '<绝对路径>'`。
- **沙箱只允许写工作区**；写外面报 `[sandbox: file access denied]` ⇒ 那是策略不是 bug，**一次提权重试**，别硬绕。
- **工具壳是 Windows PowerShell 5.1** ⇒ **直接** `Get-Content`/`Select-String` 读中文文件会按 ANSI 解码、打印成**乱码**（文件没坏）
  ⇒ 加 `-Encoding UTF8` 或用 `[IO.File]::ReadAllText`；**ASCII 模式搜索不受影响**。
- **判端口用 `netstat -ano | findstr :<port>`**（`Get-NetTCPConnection` 在本沙箱会假报"没人在听"）。
- 长任务用**后台作业**；等它靠**通知/哨兵**，不要 `sleep` 轮询。

## 3. 操作纪律

1. 写操作前**先打印目标值/路径**核对，再发命令。
2. **被中断的调用 ≠ 没执行** ⇒ 中断后必须重读状态再重跑。
3. **一次调用干完一组事**（能合并就合并）。
4. **不轮询、不 sleep**：等外部事件用哨兵/通知。
5. **大文档外包**给子代理读，只把结论带回主线。
6. **回复尽量短**：先结论与下一步。
7. **失败就是失败**：非零退出/报错/验证不一致 ⇒ 查清再往下走。
8. ⛔ **改代码前先提交或备份**；⛔ **绝不用批量字符串替换改活代码**（替换串被展开、引号被吃、BOM 会叠 —— 曾一次连坏 22 个脚本）。

## 4. 三份归位

- 通用（跨项目）→ **本文件** · 项目 → 该项目的 `AGENTS.md` · **机器专属 → 该项目的 `AGENTS.local.md`**（overlay，**不进仓库**）。
- 注入 = 本文件 ＋ **项目根 → cwd 的每一级**（`.git` 定项目根；找不到则 cwd 自身）；⛔ **没有"忽略全局那份"的开关**
  ⇒ 只想注入一份，就把 `DSH_HOME` 钉到项目根。机制细节（两种去重 · 字节预算 · 各类工作区注入什么）见**模板头部**。
