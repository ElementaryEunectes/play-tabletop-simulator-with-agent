# HARNESS_HOME_AGENTS.template.md —— 放到 harness home 的"通用纪律"模板

> **这份不是给本仓库读的**（本仓库的项目纪律在 `AGENTS.md`）。它是**跨项目那份**的可版本化源。
>
> **放哪**：`$DSH_HOME\AGENTS.md`（DSH 的"用户全局"指令文件 —— 每次请求都注入，所以只放放之四海皆准的条目）。
> **为什么留在仓库里**：那份文件在仓库之外 ⇒ 没有 git、没有 diff、没人拦它长胖。这里是它的**源**：
> 改这一份 → 复制过去 → `node`… 不需要，直接拷。本仓库的 `tts\tests\test_agents_hygiene.ps1` 会核对**项目那份**的体积与内容，
> 但**管不到全局那份**（在工作区之外）—— 所以这条复制关系是**手工纪律**，别指望有东西替你检查。
>
> ⛔ **模板里不许出现任何机器专属内容**（用户名、绝对路径、本机端口）。那些属于**项目目录下的 `AGENTS.local.md`**（overlay，不进仓库）。

## 隔离机制（DSH 的实际规则，2026-10-08 读源码确认）—— **这段不进 `---` 以下，别拷**

- **注入什么**：① `$DSH_HOME\AGENTS.md`（用户全局，**文件名是常量**，存在就第一个加）② **项目根 → 工作目录的项目链**（项目根由 `.git` 标记），
  每级找 `AGENTS.md` / `CLAUDE.md`，再找 `AGENTS.local.md` / `CLAUDE.local.md`。
- **去重只有两种**：**绝对路径**去重（同一份文件不会算两次）＋ **同目录内**去掉 trim 后内容相同的兄弟文件。
  源码原话：**跨目录即使内容完全相同也绝不合并**。最后按**字节预算**渲染（超了先丢"更宽泛的"，即离项目根更远的）。
- ⛔ **没有"忽略用户全局那份"的开关**（`USER_GLOBAL_FILE` 是常量，`instructionFileCandidates` 只管项目链）
  ⇒ 想让全局那份不参与注入，只有两条：① `$DSH_HOME` 里没有它；② **把 `DSH_HOME` 钉到项目根**（两槽同一绝对路径 ⇒ 去重成一份）。
  ⚠️ ②的代价：`DSH_HOME` 同时是 harness 的家（sessions / 凭据 / profiles）⇒ 已有状态的机器要搬迁；**新机器从一开始这么配则没有代价**。
- 后果：**模板里那份通用纪律永远和项目那份同时被注入** ⇒ 两边都必须精简，否则每个请求都在为它们付钱。

# AGENTS.md —— 平台宪章（**跨项目不变**的东西）

> 位置：`$DSH_HOME/AGENTS.md`（harness 的家）。**每次请求自动注入并计费** ⇒ 只放"放之四海皆准"的几条。
> ⛔ **不放任何单一项目的领域知识** —— 某个项目怎么干活、某局游戏的规则/坐标/状态，都在**该项目自己的文档**里。
> 本文件的**可版本化源**在仓库 `tts\docs\HARNESS_HOME_AGENTS.template.md`（改那份 → 拷到这里）。

## 1. 语言与文件约定

- **含中文的 `.ps1` 必须存成 UTF-8 带 BOM**：PS 5.1 读到无 BOM 的文件会按 ANSI 解释 ⇒ 中文注释变乱码 ⇒ **语法报错、脚本"秒挂"**。
  编辑工具重写文件常常**悄悄丢掉 BOM**；"读成字符串再带 BOM 写回"还会**每跑一次多叠一个 BOM**（三个 BOM 就足以让 `param(` 解析失败）。
  ⇒ **改完任何 `.ps1` 都要用真解析器校验一次**（`[Parser]::ParseFile`），别只靠"能跑起来"。
- 新写的一次性脚本，**注释与输出尽量用 ASCII**，最省事。
- 改配置/脚本前先 **read** 现状；**一次编辑只动一处**，改完回读确认。

## 2. 执行约定（Windows / PowerShell）

- **直接 `& xxx.ps1` 可能被执行的策略挡下** ⇒ 一律走：
  `powershell -NoProfile -ExecutionPolicy Bypass -File '<绝对路径>'`。
- 沙箱默认**只允许写工作区**：要写工作区之外会报 `[sandbox: file access denied]`
  ⇒ 那是策略不是 bug；**一次性提权重试**，别硬绕路径。
- **本 harness 的工具壳是 Windows PowerShell 5.1**（不是 PS7）⇒ **直接**用 `Get-Content` / `Select-String` 读**中文**文件会按 ANSI 解码、
  打印成**乱码**（文件本身没坏）⇒ 加 `-Encoding UTF8`，或用 `[System.IO.File]::ReadAllText`。**ASCII 模式的搜索不受影响。**
- **判端口用 `netstat -ano | findstr :<port>` 或原始 TCP 连接**：`Get-NetTCPConnection` 在本沙箱里会**假报"没人在听"**。
- 长任务用**后台作业**跑，别阻塞；等它**靠通知/哨兵**，不要 `sleep` 轮询。

## 3. 操作纪律（这几条真的每次都省钱/省事）

1. **写操作前先打印目标值/路径**并核对，再把命令发出去。
2. **被中断的调用 ≠ 没执行** ⇒ 中断后**必须重读状态再重跑**。
3. **一次调用干完一组事**（能合并的命令就合并）。
4. **不轮询、不 sleep**：等外部事件用哨兵/通知，别反复查。
5. **大文档外包**：几万字的规则书、陌生代码库、长调研 ⇒ 交给**子代理**读，只把结论带回主线。
6. **回复尽量短**：先说结论和下一步，细节按需展开。
7. **失败就是失败**：非零退出、报错、验证不一致 ⇒ **查清再往下走**，别把"看起来成了"当成成了。
8. ⛔ **改代码前先提交（或先复制备份）**：工作区未必是 git 仓库；没有版本控制时**先 Copy-Item 一份**再动。
   ⛔ **绝不用"批量字符串替换"改活代码** —— 替换串会被 PowerShell 展开、引号会被吃掉、BOM 会叠；
   要批量改就先备份，改完**逐个文件用真解析器验证**。（真实事故：一次偷懒的替换连坏了 22 个脚本。）

## 4. 项目索引与"三份归位"

- **通用**（跨项目）→ **本文件** · **项目** → 该项目的 `AGENTS.md` · **机器专属** → 该项目的 `AGENTS.local.md`（overlay，**不进仓库**）。
- ⛔ 本版本**没有"忽略用户全局那份"的开关**：想只注入一份，就把 `DSH_HOME` 钉到项目根（两个槽指向同一绝对路径 ⇒ 去重成一份）。
- **其它项目**：从**该项目目录**启动会话，即自动加载它自己的 `AGENTS.md`。
  （注入顺序 / 两种去重 / 字节预算等机制细节，见**本文件头部**，不在这里重复。）

## 5. 边界

- 领域知识写在各项目自己的文档里；本文件只在"**所有项目都适用**"时才加一条。
- 发现本文件混进了某个项目的专属内容 ⇒ **立刻搬走**（它在这里每次会话都重复计费）。
